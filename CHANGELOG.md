## [1.0.0] - 2026-11-19

### Added

- CSV to `.sys`, `.cal` and `.diag` factory data generation
- File format, rule and unit checks for the generated records
- Qt-free core (`core/`) plus a CLI and a PySide6 GUI
- Retired: the code moved into
  [factory-station](https://github.com/soccentric-stm32/factory-station); this
  repository is kept for history only
